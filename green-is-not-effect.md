# A green status is not an effect

Three public cases from the same lab. No new measurements. The point is the repeated mistake, not a fourth result.

A monitor can be alive and still prove nothing. A number can be green and still be the wrong arm. A cell can pass and still be the wrong throw.

## What only appeared to pass

In the untrusted-binary onboarding, the failures that survived the longest were verdicts computed from what the builder reported. An empty check list counted as comprehension, because an empty conjunction is true. A preflight proved a boundary on one sandbox while the green verdict named another. A guest report reproduced its pass constants with no sandbox running. The preflight path exits zero and starts nothing. The receipt's verdict field is the signal. The exit code is not.

In the memory eval, the first run gave the governed arms a negative delta. They had been given a larger content budget because they retrieved more pages. The sign flipped when the budget was fixed. The negative number was the useful one. Two model judges later agreed closely. That agreement is invariance across judges, not proof that the claims are true.

In the reranker study, the treatment arm failed its preregistered gates and the parameter stayed spent. The control arm, which was not allowed to count as a success, passed every gate. A later green confirmation was discarded because its snapshot was the one already used. The cell that counted was a fresh snapshot. A green cell on the old snapshot was a replay.

## The rule

Do not promote a status, an exit code, or a first green cell into an effect. Name what was measured, what was held fixed, and what was thrown away. If the artifact does not contain the stronger claim, the weaker sentence is the one that ships.

This page adds no project, no hostname, and no number that is not already in the three studies.
